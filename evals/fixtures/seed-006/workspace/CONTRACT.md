# Workspace Contract

Produce `FRAMEWORK_RECOMMENDATION.md`; do not modify `package.json` or `src/`.

The report must:

1. diagnose whether the current framework is the demonstrated root cause;
2. compare keeping the current stack, incremental improvement, and full rewrite;
3. separate repository facts from current external Evidence and assumptions;
4. include version, compatibility, license, and maintenance sources for every framework candidate;
5. respect a two-frontend-engineer team and a six-week maximum migration window;
6. propose one bounded spike, success/exit criteria, rollback, and an Approval Point before dependency installation or rewrite.

The snapshot contains no dependency installation authorization. Network access,
if separately allowed by the experiment controller, is for read-only official
research only.
